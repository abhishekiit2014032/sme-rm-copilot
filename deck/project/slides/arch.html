Read it top to bottom as a request path. The RM works in tools they already use: the CRM sidebar and a Teams personal tab in the pilot; a Teams bot comes only in Phase 2, after a residency sign-off. Every request enters through Entra ID sign-in and the internal Application Gateway with WAF, and the RM's identity travels all the way down as an on-behalf-of token. The orchestrator, running on AKS, is the brain: it classifies the intent, runs a fixed workflow where the use case allows, calls the tools and manages approvals for writes. It uses three services: a knowledge service for RAG over policy documents on Azure AI Search, a tool layer, tool-gateway, that wraps bank APIs and enforces entitlements, and an LLM gateway on API Management that is the only path to Azure OpenAI, which gives us one place for token limits, metrics and cost control. Guardrails sit around the orchestrator on both input and output. The dark rail on the right is what makes this bank-grade: every step is traced, evaluated and audited.
