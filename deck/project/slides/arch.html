Read it top to bottom as a request path. The RM works in tools they already use: the CRM sidebar first, then Teams and mobile. Every request passes through the bank’s SSO and API gateway, and the RM’s identity travels with it all the way down. The orchestrator is the brain: it classifies the intent, plans which tools to call, calls them, and manages approvals for writes. It uses three services: a knowledge service for RAG over documents, a tool layer that wraps bank APIs and enforces entitlements, and an LLM gateway that is the only path to any model, which gives us one place for routing, logging, PII masking and cost control. Guardrails sit around the orchestrator on both input and output. The dark rail on the right is what makes this bank-grade: every step is traced, evaluated and audited.
