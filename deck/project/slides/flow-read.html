This is one pre-meeting brief, end to end, and the numbers match the architecture plan. Everything inside the dashed line is the Bank's private network in Azure UAE North: Application Gateway inwards, and every PaaS service, including Azure OpenAI, sits on a private endpoint. One: the RM opens the brief from the CRM sidebar or the Teams tab, already signed in with Entra ID. Two: the internal Application Gateway with WAF passes it to web-bff, which validates the token, exchanges it on behalf of the RM for a token meant only for tool-gateway, and sets an 8 second deadline that every later hop respects. Three: the orchestrator runs a fixed workflow for the brief, so there is no model call to decide what to do. Four: tool-gateway checks entitlement first, against a cache of at most 60 seconds in Cosmos DB. If the customer is not in the RM's portfolio it returns 403 and no data moves. Five: it reads CRM, the core banking ODS, lending, KYC and news in parallel through the APIM system facade and ExpressRoute, each call with its own timeout and circuit breaker. Only the CRM profile is critical: if lending, the ODS, KYC or news fails, the brief still comes back with that section flagged as unavailable. Six: it masks and minimises fields, returns facts with source references, and writes one audit event per call to Event Hubs; it is the only audit producer, and the stream feeds the immutable audit store. Seven: the orchestrator masks PII and runs Prompt Shields on any fetched free text. Eight: through the APIM AI gateway, gen-large writes the wording with placeholders; it never sees or produces the numbers. Nine: the orchestrator fills the placeholders from tool output and runs the numeric and policy checks; a failing line is dropped. Ten: the verified brief goes back with sources. The facts-only sections can show after step six, about 1.7 seconds in; nothing unverified is ever streamed. The only outbound paths are Entra ID and Graph on the Microsoft backbone, Azure Monitor through a private link scope, and the news feed through the firewall allow-list.
