This is the component view behind the two flows, with every Azure service named. Colours show the tier, and the key at the top reads left to right in the order a request travels. The middle row is the request spine: the CRM sidebar or Teams tab, the internal Application Gateway with WAF, then three services on AKS: web-bff, the orchestrator and tool-gateway, and finally the APIM system facade in front of the systems of record over ExpressRoute. Above the spine are identity, keys and configuration. Entra ID does sign-in, on-behalf-of tokens and step-up. Key Vault Premium holds the approval key in an HSM: web-bff can only sign with it and tool-gateway can only read the public key. The orchestrator sits directly under Key Vault with no line to it, on purpose: it has no key. App Configuration holds feature flags and the kill switches for each use case and for all writes. Below the orchestrator is the AI tier: Content Safety for Prompt Shields, AI Language for PII masking, and the APIM AI gateway, the only path to Azure OpenAI in Azure AI Foundry, with gen-large, gen-small and embed as Regional Standard deployments in UAE North. Below tool-gateway is its data: AI Search for the policy index, Cosmos DB for sessions, drafts, the one-time token ids and the write outbox, and Event Hubs for the audit stream; tool-gateway is the only audit producer, and it also makes the calendar call to Microsoft Graph, which is not drawn here. The audit-writer, also on AKS, hash-chains each event into immutable Blob storage, geo-replicated and kept for seven years. Across everything is Azure Monitor: Application Insights with OpenTelemetry, managed Prometheus and Managed Grafana. Telemetry carries metadata only, never prompt or answer text.
