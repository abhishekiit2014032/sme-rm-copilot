    How to read this
    • Each row is one span written by one box on the architecture diagram. The coloured name is the box; the text after it is the step.
    • Rows are grouped by lane: A online request path, B controlled execution, C state + data freshness, D production operations. Bars share one time axis, so overlapping bars ran in parallel.
    • A diamond is an instant decision (a cache lookup, a gate). Amber rows are the human approval gate. Red bars blocked the request; striped bars ran degraded.
    • Attributes show what the architecture promises: model tier and tokens per call, the four identity checks on every tool call, retrieval scores against the gate threshold, citations and checks on the way out.
    • Traces carry no prompt text and no customer payloads, only names, counts, scores and timings.
